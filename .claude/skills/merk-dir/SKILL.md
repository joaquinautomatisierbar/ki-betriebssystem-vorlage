# Merk dir

1. Entscheide, wohin es gehört:
   - über die Person oder Vorlieben → `wissen/ueber-mich.md`
   - über die Firma → `wissen/firma.md`
   - über einen Kunden → `wissen/kunden/<name>.md` (aus `_vorlage.md` anlegen, falls neu)
   - eine Entscheidung mit Grund → `entscheidungen/log.md` (oben einfügen)
   - wie eine Aufgabe gemacht wird → in den passenden Ablauf in `ablaeufe/`
   - sonst → `wissen/notizen/`
2. Schreib es kurz und mit Datum (JJJJ-MM-TT). Wenn möglich mit Grund.
3. Widerspricht es etwas, das schon drin steht: Altes nicht löschen, sondern mit «ersetzt am JJJJ-MM-TT» markieren.
4. Antworte in einem Satz, wo du es gespeichert hast.
