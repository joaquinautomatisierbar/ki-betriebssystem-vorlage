# Tools

Hier liegen kleine Skripte, die die KI für dich baut, z. B. «benenne alle PDFs in diesem Ordner nach Datum und Absender um».
Jedes Tool macht genau eine Sache und steht oben in der Datei kurz erklärt.

Zugangsdaten (API-Schlüssel, Passwörter) liest ein Tool aus `.env`, nie direkt aus dem Code.
